Two words you'll see

Preset

A named set of keys for one project.

news-bot = OPENAI_API_KEY + ASKNEWS_API_KEY
Session

One approval that lets a preset's keys be used for a set time.

news-bot, for 60 minutes

What you just saw

  1. Your .env keys moved into an encrypted vault your agents can't read.
  2. An AI agent asked for the keys it needed, and said why.
  3. You approved on the envh console, with your passphrase.
  4. Only the agent's script got the keys, for one session.
  5. A low-risk key marked auto worked without asking.
  6. You denied a request you didn't expect. The agent got nothing.
  7. Every step was logged.
