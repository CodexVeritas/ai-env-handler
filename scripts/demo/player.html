envh
Human-approved secrets for scripts and AI agents
Your API keys leave your .env files, and you approve every use.

Why use envh

  • No keys in .env files. They sit in an encrypted vault owned by a separate Linux user, which you and your agents can't read.
  • You approve each use on one console. Every request shows who is asking, why, which keys, for how long and the exact command.
  • One approval covers a work session. Runs inside it start at once. Every request, decision and run is logged.
  • Works with Claude Code and Cursor. A skill teaches the agent how to ask, and a hook tells you when the console needs you.
